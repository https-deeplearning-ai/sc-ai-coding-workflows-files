# Mission

Prompt Pantry is a shared shelf where developers stock the prompts that actually work.

*"Stock your shelf. Share a prompt."*

Built as a learning project for workshop attendees exploring AI coding agents, Prompt Pantry demonstrates how to build a small React application: components, props, state, forms and tests. There is no backend, no database and no authentication. Everything lives in memory.

The site is deliberately small: a welcoming home page and a pantry board where developers can browse each other's prompts and add their own. The codebase is meant to be an approachable example of React fundamentals.
